# أرباع القرآن للتراويح

تطبيق ويب (PWA) يعرض القرآن ربعًا ربعًا بصور صفحات المصحف المدني (برواية حفص، مجمع الملك فهد)، مع التفسير الميسر والتلاوة.

- صور الصفحات مأخوذة من مشروع pyQuran / Open Mushaf (رخصة GPL-3.0)، لذلك يُوزَّع هذا المشروع بنفس الرخصة (ملف LICENSE).
- النص والتفسير من alquran.cloud، والتلاوة من everyayah.com.
- الرفع على GitHub: المتصفح يقبل 100 ملف في المرة، فارفع مجلدات `pages/0` … `pages/6` كل واحد على حدة.
- فعّل GitHub Pages من Settings → Pages (الفرع main، المجلد root).
