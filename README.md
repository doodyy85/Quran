# مصحف التراويح

تطبيق ويب (PWA) يعرض المصحف المدني ربعًا ربعًا لصلاة التراويح، مع التفسير الميسر والتلاوة وتظليل الآيات التي خارج الربع.

- صور الصفحات من مشروع pyQuran / Open Mushaf (رخصة GPL-3.0)، لذلك يُوزَّع هذا المشروع بنفس الرخصة (ملف LICENSE).
- `markers.json`: مواضع نهايات الآيات على صور الصفحات، استُخرجت تلقائيًا من الصور، وتُستخدم في التظليل.
- النص والتفسير من alquran.cloud، والتلاوة من everyayah.com.
- فعّل GitHub Pages من Settings → Pages (الفرع main، المجلد root).
